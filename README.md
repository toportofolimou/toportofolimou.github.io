# Το πορτοφόλι μου

Απλή εφαρμογή για νέους που θέλουν να οργανώσουν τα χρήματά τους:
μισθός, πάγια έξοδα, επαναλαμβανόμενες πληρωμές με υπενθυμίσεις, αποταμιεύσεις,
στόχοι εξόδων και καθημερινά έξοδα με κυκλική παράσταση. Ελληνικά και Αγγλικά.

- Δουλεύει σε κινητό, τάμπλετ και υπολογιστή, και μπαίνει στην αρχική οθόνη σαν εφαρμογή.
- Λειτουργεί και χωρίς internet.
- Τα δεδομένα μένουν μόνο στη συσκευή του χρήστη — δεν στέλνονται πουθενά.

Απλή στατική σελίδα (HTML, CSS, JavaScript) χωρίς build. Τα κείμενα και των δύο γλωσσών είναι στο `js/i18n.js`.
